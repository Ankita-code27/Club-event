# Club Events

College club event management website (React + Vite, Express, Firebase).

> Full documentation is added in Phase 13.

## Quick start
```
npm run install:all
npm run dev
```
- Frontend: http://localhost:5173
- Backend:  http://localhost:5000  (health check: /api/health)

Copy `client/.env.example` to `client/.env` and `server/.env.example` to `server/.env` before connecting Firebase (Phase 6+).
